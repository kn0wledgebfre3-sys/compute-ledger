# Climate TRACE handover: datacenters as a facility type

Prepared 2026-10-21, revised 2026-10-22, and extended on 2026-10-23 with metered figures, the reporting layer (how companies' emissions are accounted and rated), crypto-mining sites, and one table of every figure, by the Compute Ledger. Data CC BY 4.0. Everything here traces to a public record or to a file in this folder. The package was reviewed hostilely three times before sending: the handover (`review_of_this_handover.md`), the final package and brief (`review_2_final.md`), and the public ledger page (`review_3_ledger_page.md`). All three are included unedited except that local file paths were replaced with repository paths; every finding was applied or is stated as a caveat. The Texas figures were then checked independently against their documents (`review_4_texas_check.md`), and those corrections are applied. The measurements table was checked the same way on a random sample of 56 figures across every source (`review_5_measurements_check.md`); every problem found is corrected and listed there.
