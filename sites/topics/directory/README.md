# Datacentre counts in a commercial directory

`figures.csv` holds Data Center Map's count of the datacentres it lists for each country with a page in the ledger, and its worldwide total, read twice on 20 November 2026 (`review/directory_counts_2026-11-20/`).

These counts are claims, not records. The directory says its listings "are primarily submitted and maintained directly by the operators". It counts buildings, gives no size, and does not say what runs in them. They belong to the entry `global-datacentre-counts-directory-and-records`, which sets them beside the sites the ledger names from public records. Each country's page shows both numbers.

The directory changes daily. To update the counts, read the page again, twice, and add a new dated row per country; do not overwrite old ones.
