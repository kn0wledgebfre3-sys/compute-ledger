# Remaining disagreements: fixed extractor vs resolved figures (2026-10-22)

Run: `python3 tests/test_va_extraction.py` on the 182 real permit PDFs (5.pdf is an HTML error page and is skipped). 178 agree, 2 minor, 0 disagree, 2 pipeline-null. Each line below was checked against the permit text layer and, where noted, the page image in `review/va_reread/img/`.

- **73717** (minor; pipeline 5 units / 3.975 MW vs resolved 5 / 4.275): **resolved is right.** The page image (`img/73717c.png`) prints "LS1 | One (1) Generac engine-generator set, model # SD300 | 300 ekW (427 bhp)", but the OCR text layer lost the "300 ekW" cell. The pipeline counts the unit, reports it as having no kW rating in the text (MW is a partial sum, confidence `low`, reason in `extract_reason`) and does not guess a rating from the model number.
- **73995** (minor; pipeline 56 / 130.5 vs resolved 57 / 132.5): **resolved is right.** The page image (`img/73995.png`) shows Transitory Engines 5 and 6 at 2,000 kW each, and the conditions name "Transitory Engines 1 through 6". The OCR text of page 4 lost Engine 5's row and both rows' ratings. The pipeline recovers Engine 6 only, taking the rating of the row above with confidence `low`, and cannot see Engine 5.
- **52949** (pipeline-null MW; pipeline 63 units / no MW vs resolved 63 / 181.5): **counts agree; the MW is an inference, not a reading.** The permit prints only "Sixty (60) Cummins C3000 D6e engines 4,308 bhp, each" and "Three (3) Cummins DFEK engines 732 bhp, each", with no kW anywhere. The resolved 3,000 / 500 ekW comes from identical models in sibling Microsoft permits. The pipeline does not estimate (`total_standby_mw` empty, `extract_reason` says bhp only), so this stays open by design.
- **52973** (pipeline-null MW; pipeline 129 units / no MW vs resolved 129 / 374.5): **same as 52949.** "One Hundred Twenty-Four (124) … Cummins C3000 D6e engines 4,308 bhp, each" and "Five (5) Cummins DFEK engines 732 bhp, each" print bhp only. The resolved kW is inferred from sibling permits, and the pipeline leaves MW empty rather than estimate.

Not counted on either side: `5.pdf` (a 479-byte "Access Denied" HTML page, not a permit) and registration 74331 (no PDF).
